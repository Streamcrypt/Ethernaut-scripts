# Ethernaut Privacy Scripts

## Description

This repository contains a Python script for **Ethernaut Level 12 – Privacy**:

1. **`Privacy_key_extractor.py`** – An automated script that extracts the `_key` bytes directly from the constructor bytecode of a Privacy level instance, for quick and minimal-effort use.

## Features

### `Privacy_key_extractor.py`

* Input the constructor bytecode.
* Automatically extracts the `_key` bytes required to solve the level.

## Usage

### Running the automated key extractor:

```bash
python Privacy_key_extractor.py
````

* Paste the full constructor bytecode of the Privacy level instance.
* The script prints the `_key` bytes directly.

## Notes

* The script expects **even-length inputs** (especially hexadecimal strings).
* It is for **fast, direct extraction** without extra steps.
